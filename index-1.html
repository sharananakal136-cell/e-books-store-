Launch checklist

  1. Replace sample product names, descriptions and prices with your real products.
  2. Use only files you created or have permission to resell.
  3. Publish the site on a static host such as GitHub Pages.
  4. For real orders, connect a payment provider account owned by an eligible adult/business owner, if required.
  5. Use a server-side payment confirmation/webhook and protected download links. Never put secret API keys in this HTML file.
  6. Add your contact details, refund policy, privacy policy and terms before launch.

This static starter cannot securely verify payments or protect paid files by itself.
